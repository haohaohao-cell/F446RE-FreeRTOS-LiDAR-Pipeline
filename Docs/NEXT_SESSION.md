## 6. 现场踩过的三个坑（**都是今晚修的，重写会复现**）

| # | 症状 | 根因 | 修法 |
|---|---|---|---|
| 1 | 双击快捷方式**闪退** | `.cmd` 是 LF 换行，cmd.exe 双击时解析失败 | 全部改成 CRLF |
| 2 | 车**原地转圈**（两轮反向） | 蓝牙**打开后的第一次写入被吞**，`Z` 丢了 → `G` 拿上一趟位姿跑 → 航向误差 >45° | `Z` 连发两次（`bt_run.ps1`），单字母命令也发两次 |
| 3 | `demo_2`（负坐标）报**参数错误** | `-File` 模式下 `-700` 被当参数名 | 改用 `-Command` 传字面量 |

> 坑 2 与历史坑 E（晚到的 STOP 清掉新路径）是同一类：**SPP 写入不等于送达**。

## 7. 历史七个 bug（一句话版，详情见报告 §11）

| # | 一句话 |
|---|---|
| A | 栈溢出钩子设 BASEPRI=0x50，屏蔽不掉优先级 0 的 TIM7 → "TIM7 在跳但任务全停" |
| B | `osEventFlagsWait` 无事件返回 `0xFFFFFFFD`，`&1==1` 被当成 STOP |
| C | 电机在 PB6/PB7 上但装的是右轮，且极性反 → 左右对调 + `RIGHT_INVERT` |
| D | 积分限幅 120×ki0.15 = 2% 输出，积分等于禁用 → 速度只有目标 28% |
| E | 测试脚本的 `S` 晚到，清掉了新路径 |
| F | **右轮编码器 190 ns 滤波太短**，碳刷噪声被当边沿 → R/L 1.80/4.74；改 3 µs 后 1.03/1.14 |
| G | `PATH: g/r` 是开机累计值，不是本趟进度 → 判据错，1.4 m 的路 1.2 s 就"完成" |

## 11. 已知的物理限制（答辩要主动说）

1. **死区随负载升高**：空载 20–30% 不转；带载 40% 也推不动（实测左轮 4.8 s 走 2 mm，
   同一轮 100% 走 10508 counts）。所以低调试点动键在弱电池下不可用 → **必须充满电**
2. **转向段位移未建模**：见 §3 最后一段
3. **位姿不累积陀螺漂移**（航向直接赋陀螺值），但会继承陀螺零偏；上电后静止 1–2 s 再跑
4. **蓝牙是单向的**：车不发状态回来，到点只能看车、误差只能量卷尺
